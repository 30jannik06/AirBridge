**AirBridge 0.2.0 brings a proper interface:** status, settings, a live log, a tray icon and an optional "allow this device?" prompt.
Mirror your iPhone from Control Center → Screen Mirroring to a Windows PC, no app on the iPhone.

## What's new

- 🖥️ **New interface** with a side panel: *Status* (connection, address, resolution, latency), *Settings* and *Log*
- ✏️ **Rename your receiver** (the name shown on the iPhone), applied live without a restart
- 🔒 **Optional confirmation** before a new device may connect: *Allow once / Always allow / Deny*, with a list of trusted devices
- 🪟 **Window options:** always on top, automatic fullscreen when mirroring starts
- 🧷 **Tray icon:** keep running in the background, left click opens the window, `--minimized` starts hidden
- 🚀 **Start with Windows** (optional, runs in the tray)
- 📋 **Built-in log view** with copy, so bug reports are easier

## Downloads

| File | For whom |
|---|---|
| `AirBridge-Setup-0.2.0.exe` | Normal install: Program Files, Start menu, optional firewall rule |
| `AirBridge-0.2.0-portable.zip` | No install, no admin rights; settings stay next to the exe |
| `SHA256SUMS.txt` | Checksums to verify the downloads |

## Please note

- **These builds have no audio.** The AAC codec (FDK-AAC) has a licence that is not compatible with the GPL, so it cannot
  be shipped in a binary. Want sound? Build it yourself with `--features nonfree-audio`
  (see [docs/BUILDING.md](https://github.com/30jannik06/AirBridge/blob/main/docs/BUILDING.md)).
- The executable is about 5 MB larger than 0.1.0 because of the new interface (about 7 MB in total).
- The confirmation prompt is a simple "allow / deny", not a PIN. Without it, any device on your network can connect.
- Windows only, one iPhone at a time, no DRM content (Netflix, Disney+, …).
- Windows may show a SmartScreen warning because the files are not code-signed yet.

Your existing key and device name carry over from 0.1.0 (same folder), so the iPhone still recognises your receiver.

## 🇩🇪 Kurzfassung

**AirBridge 0.2.0 bringt eine richtige Oberfläche:** Status, Einstellungen, Live-Log, Tray-Symbol und eine optionale Bestätigung für neue Geräte.

- Gerätename ändern (wirkt sofort), Fenster im Vordergrund, automatisch Vollbild, Start mit Windows, im Tray weiterlaufen.
- Neue Geräte optional bestätigen („Zulassen / Immer / Ablehnen“). Das ist keine PIN.
- **Setup** oder **portable ZIP**, Prüfsummen in `SHA256SUMS.txt`. **Diese Programme haben keinen Ton** (FDK-AAC ist nicht
  GPL-kompatibel); für Ton selbst bauen mit `--features nonfree-audio`.
- Die Exe ist durch die Oberfläche etwa 5 MB größer (insgesamt ca. 7 MB). Windows kann eine SmartScreen-Warnung zeigen.
