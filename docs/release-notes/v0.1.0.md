First public release of **AirBridge**: a lean, native AirPlay screen-mirroring receiver for Windows, written in Rust.
Mirror your iPhone from Control Center → Screen Mirroring. No app on the iPhone, no Apple software on the PC.

## Highlights

- 📱 Mirror an iPhone to Windows over AirPlay (discovery, pairing, FairPlay, H.264 video)
- ⚡ Low latency: hardware-friendly Windows decoder (Media Foundation) with an SPS fix, about 3 ms decode time
- 🖥️ Resizable window that follows rotation, fullscreen with `F11` / double click / `Esc`
- 📦 One small executable (about 2 MB), no runtime dependencies
- 🔒 Unique device id and persistent key per installation, no internet access

## Downloads

| File | For whom |
|---|---|
| `AirBridge-Setup-0.1.0.exe` | Normal install: Program Files, Start menu, optional firewall rule |
| `AirBridge-0.1.0-portable.zip` | No install, no admin rights; settings stay next to the exe |
| `SHA256SUMS.txt` | Checksums to verify the downloads |

## Usage

1. PC and iPhone on the **same network** (no guest Wi-Fi with client isolation, no VPN).
2. Start AirBridge.
3. iPhone: **Control Center → Screen Mirroring → AirBridge**.

## Please note

- **These builds have no audio.** The AAC codec (FDK-AAC) has a licence that is not compatible with the GPL, so it cannot
  be shipped in a binary. Want sound? Build it yourself: `cargo build --release` (see [docs/BUILDING.md](https://github.com/30jannik06/AirBridge/blob/main/docs/BUILDING.md)).
- Windows only, one iPhone at a time. No DRM content (Netflix, Disney+, …): iOS blocks that itself.
- No PIN or password: any device on the same network can connect. Use it on networks you trust.
- Windows may show a SmartScreen warning because the files are not code-signed yet.
- Tested with one iPhone on Windows 11. Reports for other devices and iOS versions are very welcome.

## 🇩🇪 Kurzfassung

Erste öffentliche Version von **AirBridge**: ein schlanker, nativer AirPlay-Empfänger für Windows in Rust. iPhone über
Kontrollzentrum → Bildschirmsynchronisierung spiegeln, ohne App auf dem iPhone.

- **Setup** oder **portable ZIP** (Prüfsummen in `SHA256SUMS.txt`).
- **Diese Programme haben keinen Ton** (FDK-AAC ist nicht GPL-kompatibel). Für Ton selbst bauen: `cargo build --release`.
- Nur Windows, ein iPhone gleichzeitig, kein DRM-Inhalt, keine PIN: nur in vertrauenswürdigen Netzwerken nutzen.
- Windows kann eine SmartScreen-Warnung zeigen, weil die Dateien noch nicht signiert sind.
