**AirBridge 0.4.0 can tell you when a new version is out.** The update check is optional and off by default; AirBridge
still never talks to the internet unless you ask it to.

## What's new

- 🔔 **Update check:** turn on "Beim Start nach Updates suchen" in the settings, or press "Jetzt nach Updates suchen".
  If a newer version exists, a notice at the top of the panel explains what to do and opens the release page.
  Nothing is downloaded or installed automatically.
- 🔁 **Updating is easy:** run the new Setup over the old version (it closes a running AirBridge for you) or unzip the new
  portable ZIP over the old folder. Key and settings stay.
- 🚫 **One AirBridge at a time:** starting a second copy now shows a short hint instead of a confusing port error.

## Privacy

The update check sends one normal HTTPS request to `api.github.com` and nothing about you. It only reads the latest version
number and a link to our own release page, and AirBridge only ever opens links to this repository. With the check off
(the default) there is no internet access at all.

## Downloads

| File | For whom |
|---|---|
| `AirBridge-Setup-0.4.0.exe` | Normal install: Program Files, Start menu, optional firewall rule |
| `AirBridge-0.4.0-portable.zip` | No install, no admin rights; settings stay next to the exe |
| `SHA256SUMS.txt` | Checksums to verify the downloads |

## Please note

- **Music has sound in these downloads. The sound that goes with screen mirroring does not.** That one needs the
  AAC-ELD codec (FDK-AAC), whose licence is not compatible with the GPL. You can build it yourself with
  `--features nonfree-audio` (see [docs/BUILDING.md](https://github.com/30jannik06/AirBridge/blob/main/docs/BUILDING.md)).
- Windows only, one iPhone at a time, no DRM content (Netflix, Disney+, …).
- Windows may show a SmartScreen warning because the files are not code-signed yet.

Updating from 0.3.x is safe: key, name and settings carry over.

## 🇩🇪 Kurzfassung

**AirBridge 0.4.0 meldet dir, wenn eine neue Version erschienen ist.** Der Update-Check ist optional und standardmäßig aus;
ohne ihn geht AirBridge weiterhin nie ins Internet.

- Einstellungen → „Beim Start nach Updates suchen“ oder „Jetzt nach Updates suchen“. Der Hinweis öffnet die Release-Seite,
  es wird nichts automatisch installiert.
- Aktualisieren: das neue Setup über die alte Version ausführen (es schließt ein laufendes AirBridge) oder das neue ZIP über
  den alten Ordner entpacken. Schlüssel und Einstellungen bleiben.
- AirBridge startet nicht doppelt, stattdessen kommt ein kurzer Hinweis.
- Ton beim Bildschirmspiegeln gibt es weiterhin nur in selbst gebauten Versionen (`--features nonfree-audio`).
