A small polish release: **AirBridge now has an icon** and the project is easier to read and contribute to. No behaviour
changes for mirroring or music.

## What's new

- 🖼️ **Icon:** `airbridge.exe` has a proper icon and version information (Explorer, taskbar, file properties). The installer uses it too.
- 📸 **Screenshots** in the README
- 📝 **Code comments are now in English**, which makes contributing easier
- 🔎 Requests AirBridge does not know yet (for example AirPlay video by link) are written to the log with their content,
  which helps to analyse what the iPhone sends

## Downloads

| File | For whom |
|---|---|
| `AirBridge-Setup-0.3.1.exe` | Normal install: Program Files, Start menu, optional firewall rule |
| `AirBridge-0.3.1-portable.zip` | No install, no admin rights; settings stay next to the exe |
| `SHA256SUMS.txt` | Checksums to verify the downloads |

## Please note

- **Music has sound in these downloads. The sound that goes with screen mirroring does not.** That one needs the
  AAC-ELD codec (FDK-AAC), whose licence is not compatible with the GPL. You can build it yourself with
  `--features nonfree-audio` (see [docs/BUILDING.md](https://github.com/30jannik06/AirBridge/blob/main/docs/BUILDING.md)).
- Windows only, one iPhone at a time, no DRM content (Netflix, Disney+, …).
- Windows may show a SmartScreen warning because the files are not code-signed yet.

Updating from 0.3.0 is safe: key, name and settings carry over.
