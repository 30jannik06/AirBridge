# Code of Conduct

We want AirBridge to be a friendly place to ask questions and share work.

**Do:** be respectful, assume good intent, give constructive feedback, help newcomers.

**Don't:** harass, insult or discriminate against anyone, publish other people's private information, or spam.

Maintainers may edit or remove comments, issues and contributions that break these rules, and may block repeat offenders.

To report a problem, contact the maintainer through the email address on their GitHub profile
([@30jannik06](https://github.com/30jannik06)).
